# OpenCode Agents

This directory will hold OpenCode agent definitions. They are meant to **mirror the MFI Agent Registry** (`../../docs/governance/AGENT_REGISTRY.md`), not replace it.

- The registry and `../../docs/governance/AGENT_STANDARD.md` remain the source of truth.
- Each definition here should reference its prompt under `prompts/` instead of duplicating it.
- Definitions are added milestone by milestone (see `../../docs/ROADMAP.md`). Nothing is defined yet.
