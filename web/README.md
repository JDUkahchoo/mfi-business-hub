# web/ - MFI Control Plane (planned)

This will become the **Cloudflare-hosted MFI Control Plane**: web interface, users, authentication, permissions, approvals, central database, agent registry, tasks, and audit logs.

**Status: not started.** No front end is built yet (Milestone 5). The Control Plane never talks to LM Studio directly; local compute is reached only through registered worker nodes.

See the [Hybrid Architecture](../docs/architecture/HYBRID_ARCHITECTURE.md) for the approved boundary. Framework and Cloudflare product choices remain future implementation decisions.
